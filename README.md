# 💰 FinanVibe AI - Gestão Financeira Inteligente

> Conceito de aplicativo de finanças pessoais impulsionado por Inteligência Artificial e desenvolvido utilizando a abordagem de **Vibe Coding**.

---

## 📌 Resumo do Conceito
O **FinanVibe AI** é um assistente financeiro pessoal projetado para simplificar o controle de orçamentos, gastos diários e metas de investimentos. Através do uso de IA, o app categoriza automaticamente despesas, analisa hábitos de consumo e oferece insights personalizados para ajudar o usuário a economizar e atingir seus objetivos financeiros sem complicação.

---

## 🎯 PRD / Prompt Final Utilizado (Prompt para Copilot/Lovable)

```text
Atue como um Engenheiro de Software e Designer UX/UI especialista na criação de aplicações financeiras. 
Crie a estrutura conceitual e o protótipo de interface para o "FinanVibe AI", um App de Organização de Finanças Pessoais com IA.

Requisitos do Projeto:
1. Painel Principal (Dashboard):
   - Resumo de Saldo Atual, Receitas e Despesas do mês.
   - Gráfico visual de gastos por categoria (Alimentação, Transporte, Lazer, etc.).
2. Funcionalidade de IA (Assistente de Finanças):
   - Módulo para categorização automática de transações via texto ou voz.
   - Gerador de insights preditivos (ex.: "Se continuar nesse ritmo, você excederá seu orçamento de lazer em 15%").
3. Tela de Metas e Objetivos:
   - Definição de metas de economia com barra de progresso visual.
4. Design & Usabilidade:
   - Interface moderna, limpa e com modo escuro (Dark Mode).
   - Componentes responsivos e intuitivos.
